# US-02 · Ambiente de desenvolvimento com Docker

**Como** desenvolvedor, **quero** subir Postgres e todo o ambiente com um comando **para** desenvolver e testar sem configuração manual.

## Contexto mínimo (ler só isto)

- `docs/arquitetura/visao-geral.md` §6 (ambientes) e §7 (variáveis)
- `docs/arquitetura/dados.md` §1

## Critérios de aceite

- [ ] **CA1:** dado Docker instalado, quando rodo `docker compose -f infra/compose.dev.yml up -d`, então `postgres:16-alpine` fica `healthy` com volume persistente.
- [ ] **CA2:** dado o primeiro start, quando consulto os bancos, então existem `amazonafiliados` e `amazonafiliados_test` (script de init).
- [ ] **CA3:** dado `.env.example`, quando comparo com `visao-geral.md` §7, então toda variável da tabela está presente, sem segredo real.
- [ ] **CA4:** dado o `.env` copiado do exemplo, quando rodo `pnpm dev`, então api, worker e web sobem juntos (concurrently) e o README tem o quickstart.

```bash
docker compose -f infra/compose.dev.yml up -d --wait
docker compose -f infra/compose.dev.yml exec postgres psql -U postgres -lqt | grep amazonafiliados
pnpm lint
```
