# US-10 · Enriquecimento: preço de lista e desconto

**Como** visitante, **quero** ver o desconto real dos produtos mais vendidos **para** decidir pela oferta.

## Contexto mínimo (ler só isto)

- `docs/worker/coleta.md` §5 (política e cap), §8 (enriquecimento), §9
- `docs/arquitetura/dados.md` §3 (selo de desconto)

## Critérios de aceite

- [ ] **CA1:** dado o enrich, quando roda, então processa só o top 10 de cada categoria, no máximo uma vez por dia por produto.
- [ ] **CA2:** dado a página do produto (fixture), quando parseada, então `list_price` é extraído; se ausente, fica `null`.
- [ ] **CA3:** dado o cap diário de requisições, quando o enrich roda, então usa o mesmo fetcher educado e para ao atingir o cap.
- [ ] **CA4:** dado `list_price` maior que o preço atual, quando a API calcula o selo, então o desconto aparece conforme `dados.md` §3.
