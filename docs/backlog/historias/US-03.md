# US-03 · CI no GitHub Actions

**Como** Product Owner, **quero** CI no GitHub rodando lint, tipos, testes e build **para** nenhuma mudança quebrada entrar na `main`.

## Contexto mínimo (ler só isto)

- `docs/arquitetura/adr/ADR-001-monorepo-typescript.md`
- `docs/processo/scrum.md` §5 (DoD)

## Critérios de aceite

- [ ] **CA1:** dado um push ou PR, quando o workflow `ci` roda, então executa pnpm install (com cache), `pnpm lint`, `pnpm typecheck`, `pnpm test` e `pnpm build`.
- [ ] **CA2:** dado o job de testes, quando roda, então há um service `postgres:16` e `DATABASE_URL_TEST` aponta para ele.
- [ ] **CA3:** dado o repositório privado criado pelo PO, quando faço push, então o remoto `origin` existe e o primeiro run do CI fica verde.
