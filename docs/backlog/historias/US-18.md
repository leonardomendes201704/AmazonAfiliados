# US-18 · Login do admin

**Como** dono do site, **quero** entrar no painel admin com senha segura **para** gerenciar o site sem expor o painel.

## Contexto mínimo (ler só isto)

- `docs/arquitetura/api.md` §4 (admin e login)
- `docs/arquitetura/visao-geral.md` §5 (fluxo do admin) e §7
- `docs/frontend/vitrine.md` §10 (admin)
- `docs/arquitetura/dados.md` §2 (tabela `sessions`)

## Critérios de aceite

- [ ] **CA1:** dado a senha correta, quando `POST /api/admin/login`, então 200 e cookie `sid` com `httpOnly`, `Secure` e `SameSite=Lax`; senha errada devolve 401.
- [ ] **CA2:** dado 5 tentativas erradas seguidas, quando tento a sexta, então 429 (rate limit no login).
- [ ] **CA3:** dado `pnpm --filter api hash-senha`, quando informo uma senha, então imprime o hash argon2 para `ADMIN_PASSWORD_HASH`.
- [ ] **CA4:** dado sem sessão, quando abro `/admin`, então vou para `/admin/login`; com sessão, `/api/admin/me` responde 200 e o logout invalida a sessão.
- [ ] **CA5:** dado o build web, quando listo os chunks, então o admin é um chunk lazy fora do bundle da vitrine.
