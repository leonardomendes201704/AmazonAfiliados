# US-23 · Compose de produção atrás do proxy existente

**Como** dono do site, **quero** o compose rodando atrás do proxy que já existe na VPS **para** publicar sem derrubar os outros sites.

## Contexto mínimo (ler só isto)

- `docs/infra/vps-hostinger.md` §2, §3 (descobrir o proxy), §5 e §6 (rota no proxy)
- `docs/arquitetura/adr/ADR-006-deploy-vps-compartilhada.md`

## Critérios de aceite

- [ ] **CA1:** dado `infra/compose.proxy.yml`, quando valido com `docker compose -f infra/compose.yml -f infra/compose.proxy.yml config -q`, então usa a rede externa `PROXY_NETWORK` e `container_name` fixo do web.
- [ ] **CA2:** dado `infra/compose.hostport.yml`, quando valido, então publica o web em porta do host como alternativa.
- [ ] **CA3:** dado o proxy identificado, quando leio `vps-hostinger.md` §6, então o snippet de rota corresponde ao proxy real.
- [ ] **CA4:** dado o acesso SSH, quando o `devops` lista containers e redes da VPS, então identifica o proxy e a rede sem alterar os outros sites.
