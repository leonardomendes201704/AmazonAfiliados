# US-11 · API pública do catálogo

**Como** vitrine, **quero** uma API pública do catálogo **para** listar, filtrar e buscar produtos com preço seguro.

## Contexto mínimo (ler só isto)

- `docs/arquitetura/api.md` §1 (convenções) e §2 (vitrine)
- `docs/arquitetura/dados.md` §3 (regras) e §2
- `docs/arquitetura/adr/ADR-002-api-fastify-drizzle.md`
- `docs/arquitetura/adr/ADR-005-preco-com-data-e-chave.md`

## Critérios de aceite

- [ ] **CA1:** dado a API no ar, quando faço `curl localhost:3000/api/saude`, então 200 com JSON; erros seguem `application/problem+json`.
- [ ] **CA2:** dado o seed, quando `GET /api/produtos?categoria=<slug>&q=celular&f=oferta&min=10&max=500&ordem=posicao&pagina=1`, então a resposta bate com o schema de `shared` e traz facetas e paginação.
- [ ] **CA3:** dado busca `cafe`, quando o produto é "Café", então ele é encontrado (accent-insensitive).
- [ ] **CA4:** dado `show_price` desligado ou preço com mais de 24 h, quando listo produtos, então o campo de preço vem `null` (decisão no servidor).
- [ ] **CA5:** dado `GET /api/categorias` e `/api/config/publica`, então respondem com cabeçalhos de cache e testes com `fastify.inject` passam contra o banco de teste.
