# US-31 · Biblioteca de criativos no admin

**Como** dono do site, **quero** uma biblioteca de criativos no admin **para** gerar, baixar e acompanhar os cliques de cada criativo.

## Contexto mínimo (ler só isto)

- `docs/arquitetura/api.md` §4 (admin)
- `docs/frontend/vitrine.md` §10
- `docs/arquitetura/dados.md` §2 (`creatives`, `clicks`)
- `docs/arquitetura/adr/ADR-007-criativos-satori.md`

## Critérios de aceite

- [ ] **CA1:** dado `POST /api/admin/criativos` com categoria e formato, quando chamo, então enfileira a geração e devolve 202.
- [ ] **CA2:** dado `GET /api/admin/criativos`, quando chamo, então lista os criativos com formato, data e cliques; o download do PNG responde `image/png`.
- [ ] **CA3:** dado a página Criativos, quando abro, então mostra preview, botão baixar PNG, copiar link UTM e cliques por criativo.
- [ ] **CA4:** dado rotas sem sessão, quando chamo, então 401.
