# US-26 · Logs, saúde e alertas

**Como** dono do site, **quero** alertas no Telegram e logs estruturados **para** saber logo quando algo quebra.

## Contexto mínimo (ler só isto)

- `docs/infra/vps-hostinger.md` §11 (logs, saúde e alertas)
- `docs/worker/coleta.md` §10 (alertas e observabilidade)
- `docs/arquitetura/visao-geral.md` §7 (`TELEGRAM_*`, `AFFILIATE_TAG`)

## Critérios de aceite

- [ ] **CA1:** dado `alerts/telegram.ts`, quando o worker envia um alerta, então chama a API do Telegram com o token do env (teste com mock) e não registra o token em log.
- [ ] **CA2:** dado o job `health`, quando roda a cada 5 min, então checa a saúde da API, o status do backup, dados com mais de 24 h e a última execução diferente de `ok`.
- [ ] **CA3:** dado uma falha detectada, quando o job roda, então envia 1 alerta e não repete enquanto o problema não mudar.
- [ ] **CA4:** dado os containers, quando leio os logs, então saem em JSON estruturado com rotação configurada.
