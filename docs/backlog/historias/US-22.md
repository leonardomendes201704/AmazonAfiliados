# US-22 · Imagens Docker de produção

**Como** dono do site, **quero** imagens Docker de produção enxutas e seguras **para** rodar tudo na VPS com pouca memória.

## Contexto mínimo (ler só isto)

- `docs/infra/vps-hostinger.md` §5 (compose) e §12 (segurança, CSP)
- `docs/arquitetura/adr/ADR-006-deploy-vps-compartilhada.md`
- `docs/arquitetura/visao-geral.md` §2 (containers)

## Critérios de aceite

- [ ] **CA1:** dado cada Dockerfile (api, worker, web), quando faço `docker build`, então a imagem multi-stage constrói e roda como usuário não-root.
- [ ] **CA2:** dado `infra/compose.yml`, quando subo, então cada serviço tem `mem_limits`, logging com rotação e healthcheck, somando cerca de 1,3 GB ou menos.
- [ ] **CA3:** dado o Caddy do web, quando acesso `/` e rota desconhecida, então serve a SPA (fallback); `/api` e `/r` vão para `api:3000`.
- [ ] **CA4:** dado uma resposta do web, quando inspeciono os cabeçalhos, então há CSP e demais cabeçalhos de segurança de §12.

